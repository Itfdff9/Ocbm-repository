# OCBM mockups — image host for Shopify listings

- `dreams/logo/` — cleaned DREAMS Fastpitch Parent logo (300dpi PNG, transparent)
- `dreams/g5000/` — Gildan 5000 tee front mockups (54 colors)
- `dreams/g18000/` — Gildan 18000 crewneck front mockups (40)
